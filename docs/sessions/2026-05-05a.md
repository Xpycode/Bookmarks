```
  app.js            Tree render, bookmarks render, drag&drop, search, dialogs

  .htaccess         Deny all (protects bookmarks.sqlite)

```

## Schema (SQLite)

```sql
settings(key TEXT PRIMARY KEY, value TEXT)
categories(id INTEGER PK, name TEXT, parent_id INTEGER FK→categories ON DELETE CASCADE, sort_order INTEGER)
bookmarks(id INTEGER PK, category_id INTEGER FK→categories ON DELETE CASCADE,
          title TEXT, url TEXT, notes TEXT, sort_order INTEGER, created_at INTEGER)
```

WAL mode + foreign keys ON. Indexes on `(parent_id, sort_order)` and `(category_id, sort_order)`.

## API surface (POST `index.php?r=api&action=…`)

Read: `list`, `search`. Mutating (CSRF-required):
`add_category`, `rename_category`, `delete_category`, `reorder_categories`,
`add_bookmark`, `update_bookmark`, `delete_bookmark`, `reorder_bookmarks`.

Import is `POST index.php?r=import` (multipart) with `csrf` field + `file` field.

## Importer behaviour

- Parses Netscape format with a tag-by-tag walk (more robust than regex line-mode).
- `<H3>` opens a folder, following `</DL>` closes it. `<A HREF>` adds a bookmark to the current folder.
- Folder hierarchy is preserved verbatim.
- Top-level orphan bookmarks (rare in clean exports) land in an auto-created `Imported` category.
- Whole import wrapped in a transaction; rolled back on failure.

## Frontend notes

- `Sortable.js` 1.15.2 from jsDelivr CDN for drag & drop.
- Categories: drag rows between any `<ul>` to reparent + reorder in one POST.
- Bookmarks: reorder within a list via Sortable; cross-category move via native HTML5 drag onto a sidebar row (`dragstart`/`drop` handlers, separate from Sortable to allow drops outside the list).
- Search: 200ms debounce, full-width overlay, click-to-open in new tab.
- Theme: `prefers-color-scheme` default, manual toggle stored in `localStorage`.
- Expanded categories persisted in `localStorage`; ancestors auto-expand when a deep category is selected.

## Security

- Bcrypt password (PHP `password_hash` default cost).
- HttpOnly + SameSite=Lax session cookie; `Secure` when behind HTTPS or `X-Forwarded-Proto: https` (Strato uses this when SSL is terminated upstream).
- Session ID regenerated on login.
- CSRF token in `<meta name="csrf-token">`, validated via `hash_equals` for all mutating endpoints.
- `data/` and `lib/` blocked from web access via `.htaccess` (covers both modern `Require all denied` and legacy `Deny from all`).
- Login throttled with 500ms `usleep` on failure to slow brute force attempts.
